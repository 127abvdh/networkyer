# شبکه‌یار - نسخه کامل‌تر قابل اجرا

## اجرا
1. Python 3.10+ نصب باشد.
2. در پوشه پروژه اجرا کنید:
   pip install -r requirements.txt
3. سپس:
   python app.py
4. مرورگر را روی http://127.0.0.1:5000 باز کنید.

## امکانات فعلی
- ثبت‌نام و ورود واقعی با SQLite
- کد و لینک معرف
- ثبت parent برای ساخت شبکه
- داشبورد کاربر
- شمارش معرف مستقیم و کل مجموعه
- موجودی و درخواست برداشت
- ثبت شماره کارت در زمان برداشت
- API ساده آمار کاربران

## نکته
این نسخه هنوز برای دریافت پول واقعی از تبلیغات یا پرداخت خودکار آماده انتشار عمومی نیست.
برای نسخه تولیدی باید احراز هویت، ضدتقلب، مدیریت تبلیغات، قوانین دقیق پورسانت، پنل ادمین، لاگ امنیتی، رمزنگاری/مدیریت امن داده‌های بانکی و اتصال پرداخت قانونی اضافه شود.
